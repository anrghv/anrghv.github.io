Project 01  ·  HSF-India Fellowship

H → WW* → eμ + MET Analysis

Using CMS 2016 Ultra-Legacy NanoAOD Open Data

GitHub Docs
Overview

Developing a complete analysis pipeline for the Higgs boson decaying into two W bosons in the opposite-sign, different-flavour (eμ) final state via the ggH production channel. The project uses CMS 2016 Ultra-Legacy Open Data to probe Standard Model physics while demonstrating the scope of LHC Open Data for education and research.

Physics Strategy
  • Kinematic Discrimination — Higgs Transverse Mass (mT) as primary discriminant between signal and backgrounds.
  • Spin Correlation — Small opening angle Δφ(eμ) exploited to separate spin-0 Higgs decays from continuum WW production.
  • Background Suppression — b-jet veto to suppress top-quark (tt̄) backgrounds; MET requirements to reject Drell-Yan processes.
  • Jet Categorisation — Events sorted into orthogonal 0-jet, 1-jet, and 2-jet bins to isolate gluon-fusion signal regions.
  • Control Regions — Dedicated Top and Drell-Yan control regions to normalise backgrounds directly from data.
Technical Pipeline
  • Core Stack — Uproot (I/O), Awkward Array (jagged structures), Vector (4-vector arithmetic), Hist (yield accumulation).
  • Distributed Computing — Dask for scalable parallel processing of millions of NanoAOD events.
  • Statistical Inference — CMS Combine for simultaneous profile likelihood fits; achieved r = 1.00 ± 0.71, 1.4σ significance.
  • Scale Factors — Trigger, lepton ID, and isolation corrections applied to simulation weights.

Project 02  ·  M.Sc. Thesis

Drell-Yan Process at CMS

Data Analysis of Z/γ* → ℓℓ at the CMS Experiment

GitHub
Overview

Master's thesis centred on the Drell-Yan process at the LHC, working with real experimental and Run 2 Monte Carlo data from the CMS experiment to study Standard Model processes. The analysis focused on the Z → μμ channel, isolating a clean Z boson signal from dominant backgrounds.

Analysis Highlights
  • Signal Extraction — Isolation of the Z mass peak through precision event selection and background suppression.
  • Event Selection — Optimised kinematic cuts, lepton isolation criteria, and data quality requirements.
  • Background Rejection — Suppression of simulated and electroweak backgrounds to obtain a clean signal region.
  • Statistical Analysis — Signal significance evaluation and distribution properties using CMS Run-2 MC samples.
Technical Implementation

C++-based ROOT scripts for event filtering, selection, and histogram production. Structured workflows from initial data handling to final statistical interpretation, providing a foundation in collider data analysis and Monte Carlo validation.
